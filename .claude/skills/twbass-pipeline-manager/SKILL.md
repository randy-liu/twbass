## 建議執行順序

### 第一層（基底，可並行）
1. `0A`（無需上傳）
2. `0B`（無需上傳，與 0A 並行）

### 第二層
3. `0C`（上傳：0A1 + 0B）
4. `0D`（上傳：0A1 + 0B + 0C1）

### 第三層（多組可並行）
5. `1A`（上傳：0D1）
6. `1B`（上傳：0D1；**5 和 6 可並行**）
7. `2A`（上傳：0D1；可加 1A）
8. `2B`（上傳：0D1；**7 和 8 可並行**）
9. `2C`（上傳：0D1 + 2A；需等 2A 完成）

### 第四層
10. `3A`（上傳：0D1 + 1A + 2A + 2B；可加 2C）
11. `3B`（上傳：0D1 + 1B1 + 2A + 2B + 3A；可加 2C）

### 補充卷（主鏈完成後，**12 和 13 可並行**）
12. `SUP-E`（上傳：0A1 + 0C1 + 0D1；可選 2A）
13. `SUP-D`（上傳：2A + 2B + 0D1 + 3A；**與 SUP-E 無相依**，下游整合在 2A/3A/3B 進行）

### 第五層（繁殖生態）
14. `4A`（上傳：0D1；可加 0B）
15. `4B`（上傳：0D1 + 1B + 4A）

## 重要備注

- **上游引用一律使用最新版**：0A→0A1, 0C→0C1, 0D→0D1, 1B→1B1, 3B→3B1
- **母版（0–4 不帶字母後綴）**只用於規格參考，不給 Gemini 執行
- **Zone-B 補丁缺漏的影響**：如果引用 1A/2C/3A/4A/4B 且關心桃竹苗地區，要提醒使用者該卷 Zone-B 補丁尚未完成，結論對 Zone-B 信心等級降為「中」
- **0A/0B 可並行**，1A/1B 可並行，2A/2B 可並行（各組互無相依）
